# 22051_DSP
-----------------------
These files in assignment 2 in course 22051 at DTU, was developed using Matlab2024b. In Matlab the GUI designer was used to create the 10-band EQ to simulate how a EQ could worked. If you wan't to run the EQ, just download the equalizer_GUI dict, unzip it, place the folder inside Matlab. Now run the tes.m file and the EQ should be up an running.
